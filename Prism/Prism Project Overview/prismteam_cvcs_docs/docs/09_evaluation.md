# Evaluation Plan

## Purpose

The evaluation must compare the retrieval quality of vision, graph, and hybrid representations on complete and partial floor plan queries.

## Systems to compare

```text
Vision-only retrieval
Graph feature retrieval
GNN graph retrieval
Vision + Graph hybrid retrieval
```

Optional later systems:

```text
K-D tree structural retrieval
room-level Maticad retrieval
```

## Query types

Evaluate each system on:

```text
complete raster query
complete graph query
masked raster query
partial graph query
semantic constraint query
hybrid raster + graph query
```

## Retrieval metrics

Standard retrieval metrics:

```text
Recall@1
Recall@5
Recall@10
MRR
nDCG
Top-k accuracy
```

The original full plan should be considered the primary positive target when the query is generated by masking a complete floor plan.

## Semantic compatibility metrics

These metrics measure whether retrieved layouts match the query at the room-program level.

```text
room count accuracy
room type histogram similarity
bedroom count match
bathroom count match
kitchen/living presence
area distribution similarity
```

## Topological metrics

These metrics measure whether retrieved layouts preserve spatial relations.

```text
adjacency precision
adjacency recall
adjacency F1
graph edit distance
degree distribution similarity
required adjacency satisfaction
spatial relation histogram similarity
```

## Partial retrieval metrics

Evaluate robustness under different mask levels:

```text
10 percent
30 percent
50 percent
70 percent
```

For each level, report:

```text
Recall@K
MRR
room type similarity
adjacency F1
functional constraint satisfaction
```

## Qualitative evaluation

For selected queries, generate visual grids:

```text
complete query -> top-10 retrieved plans
partial raster query -> top-10 retrieved plans
partial graph query -> top-10 retrieved plans
hybrid query -> top-10 retrieved plans
```

Each grid should show both image results and the main scores.

## Validation split

Use a fixed dataset split:

```text
train: 70 percent
validation: 15 percent
test: 15 percent
```

The split must be saved and reused across all experiments.

## Reproducibility requirements

Every experiment should save:

```text
config file
random seed
model checkpoint if applicable
embedding file
FAISS index
retrieval results
metrics JSON
qualitative grids
```
